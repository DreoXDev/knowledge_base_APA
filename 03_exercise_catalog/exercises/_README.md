# exercises

Contiene una nota per ogni esercizio catalogato.

## Nomi file

```txt
ex_<topic>_<source>_<number>.md
```

## Template

Usare `templates/exercise_template.md`.

## Errori da evitare

- Non creare note senza appello di provenienza.
- Non omettere metodo e teoria collegati quando noti.
- Non segnare come risolto un esercizio non verificato.
