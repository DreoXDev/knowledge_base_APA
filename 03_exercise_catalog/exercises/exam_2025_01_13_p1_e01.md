# exam_2025_01_13_p1_e01 — LCS con al massimo 3 rossi e al massimo 2 blu

> [!Info]

> * **Stato**: cataloged
> * **Tipologia**: Programmazione dinamica su sequenze
> * **Pattern**: [[parte_i_dynamic_programming_patterns]], [[metodo_programmazione_dinamica_lcs_vincoli_colori]]

## 1. Problema

Date due sequenze $X = \langle x_1, \dots, x_m \rangle$ e $Y = \langle y_1, \dots, y_n \rangle$ su un alfabeto $S$, ogni simbolo ha colore rosso ($R$), blu ($B$) o nero ($N$) secondo la funzione:

$$
col: S \to \{R, B, N\}
$$

Si vuole determinare la lunghezza massima di una sottosequenza comune di $X$ e $Y$ che contenga:
* Al massimo 3 simboli rossi;
* Al massimo 2 simboli blu.

---

## 2. Pattern Riconosciuto

Si tratta di una **più lunga sottosequenza comune (LCS) con vincoli multipli di budget** sul numero di simboli di determinati colori inclusi nella soluzione.
Poiché la soluzione deve rispettare i due budget in modo indipendente, non è possibile risolvere una LCS classica e poi filtrare i caratteri. Dobbiamo integrare i due budget direttamente nello stato della programmazione dinamica, espandendo la tabella di ricerca con due dimensioni extra:
* Una risorsa $r$ per gestire il budget di simboli rossi ancora utilizzabili ($0 \le r \le 3$);
* Una risorsa $b$ per gestire il budget di simboli blu ancora utilizzabili ($0 \le b \le 2$).

---

## 3. Modello di Programmazione Dinamica

### 1. Definizione dei Coefficienti
Definiamo la tabella DP:

$$
C[i, j, r, b]
$$

per $0 \le i \le m$, $0 \le j \le n$, $0 \le r \le 3$, e $0 \le b \le 2$.
Il coefficiente $C[i, j, r, b]$ rappresenta la lunghezza massima di una sottosequenza comune tra i prefissi $X_i = \langle x_1, \dots, x_i \rangle$ e $Y_j = \langle y_1, \dots, y_j \rangle$ contenente al massimo $r$ simboli di colore rosso e al massimo $b$ simboli di colore blu.

### 2. Caso Base
Se una qualsiasi delle due sequenze considerate è vuota (prefisso di lunghezza $0$), la lunghezza della LCS comune è necessariamente $0$, per qualsiasi valore di budget disponibile:

$$
C[0, j, r, b] = 0 \quad \forall j \in \{0, \dots, n\}, r \in \{0, \dots, 3\}, b \in \{0, \dots, 2\}
$$

$$
C[i, 0, r, b] = 0 \quad \forall i \in \{0, \dots, m\}, r \in \{0, \dots, 3\}, b \in \{0, \dots, 2\}
$$

### 3. Passo Ricorsivo
Per $i \ge 1$, $j \ge 1$, $0 \le r \le 3$, $0 \le b \le 2$:

#### Caso A: Se $x_i \ne y_j$
Non è possibile far coincidere i due simboli finali. Riduciamo il problema escludendo singolarmente l'ultimo elemento di ciascuna sequenza:

$$
C[i, j, r, b] = \max
\begin{cases}
C[i-1, j, r, b] \\
C[i, j-1, r, b]
\end{cases}
$$

#### Caso B: Se $x_i = y_j$
Possiamo decidere di includere il simbolo coincidente nella LCS o ignorarlo. La decisione dipende dal colore del simbolo:

1. **Se $col(x_i) = N$ (Nero)**: non consuma alcuna risorsa.
   $$
   C[i, j, r, b] = \max
   \begin{cases}
   C[i-1, j, r, b] \\
   C[i, j-1, r, b] \\
   1 + C[i-1, j-1, r, b]
   \end{cases}
   $$

2. **Se $col(x_i) = R$ (Rosso)**: consuma $1$ unità di budget rosso.
   * Se $r > 0$:
     $$
     C[i, j, r, b] = \max
     \begin{cases}
     C[i-1, j, r, b] \\
     C[i, j-1, r, b] \\
     1 + C[i-1, j-1, r-1, b]
     \end{cases}
     $$
   * Se $r = 0$: il simbolo rosso non può essere preso (risorsa esaurita).
     $$
     C[i, j, 0, b] = \max
     \begin{cases}
     C[i-1, j, 0, b] \\
     C[i, j-1, 0, b]
     \end{cases}
     $$

3. **Se $col(x_i) = B$ (Blu)**: consuma $1$ unità di budget blu.
   * Se $b > 0$:
     $$
     C[i, j, r, b] = \max
     \begin{cases}
     C[i-1, j, r, b] \\
     C[i, j-1, r, b] \\
     1 + C[i-1, j-1, r, b-1]
     \end{cases}
     $$
   * Se $b = 0$: il simbolo blu non può essere preso (risorsa esaurita).
     $$
     C[i, j, r, 0] = \max
     \begin{cases}
     C[i-1, j, r, 0] \\
     C[i, j-1, r, 0]
     \end{cases}
     $$

### 4. Coefficiente della Soluzione Finale
La lunghezza della LCS ottima che rispetta le specifiche (al massimo 3 rossi e al massimo 2 blu) è data da:

$$
C[m, n, 3, 2]
$$

---

## 4. Algoritmi

### Algoritmo Bottom-Up
L'algoritmo riempie la tabella DP in modo iterativo.

```text
LCS_Colori_BottomUp(X, Y, m, n):
    Alloca C[0..m, 0..n, 0..3, 0..2] e inizializza a 0

    // I casi base C[0, j, r, b] = 0 e C[i, 0, r, b] = 0 sono già soddisfatti dall'inizializzazione.

    for i from 1 to m:
        for j from 1 to n:
            for r from 0 to 3:
                for b from 0 to 2:
                    if X[i] != Y[j]:
                        C[i, j, r, b] = max(C[i-1, j, r, b], C[i, j-1, r, b])
                    else:
                        // X[i] == Y[j]
                        val_no_prendi = max(C[i-1, j, r, b], C[i, j-1, r, b])
                        
                        if col(X[i]) == 'N':
                            val_prendi = 1 + C[i-1, i-1, r, b]
                            C[i, j, r, b] = max(val_no_prendi, val_prendi)
                            
                        elif col(X[i]) == 'R':
                            if r > 0:
                                val_prendi = 1 + C[i-1, j-1, r-1, b]
                                C[i, j, r, b] = max(val_no_prendi, val_prendi)
                            else:
                                C[i, j, r, b] = val_no_prendi
                                
                        elif col(X[i]) == 'B':
                            if b > 0:
                                val_prendi = 1 + C[i-1, j-1, r, b-1]
                                C[i, j, r, b] = max(val_no_prendi, val_prendi)
                            else:
                                C[i, j, r, b] = val_no_prendi
                                
    return C
```

### Algoritmo di Ricostruzione
Procedura ricorsiva all'indietro per estrarre la stringa ottima. Viene chiamata inizialmente con `Ricostruisci(X, Y, C, m, n, 3, 2)`.

```text
Ricostruisci(X, Y, C, i, j, r, b):
    if i == 0 or j == 0:
        return ""
        
    if X[i] != Y[j]:
        if C[i-1, j, r, b] >= C[i, j-1, r, b]:
            return Ricostruisci(X, Y, C, i-1, j, r, b)
        else:
            return Ricostruisci(X, Y, C, i, j-1, r, b)
            
    else: // X[i] == Y[j]
        // Dobbiamo verificare se l'ottimo è stato prodotto prendendo o escludendo il simbolo
        colore = col(X[i])
        
        if colore == 'N':
            if C[i, j, r, b] == 1 + C[i-1, j-1, r, b]:
                return Ricostruisci(X, Y, C, i-1, j-1, r, b) + X[i]
            // Altrimenti non è stato preso
            
        elif colore == 'R' and r > 0:
            if C[i, j, r, b] == 1 + C[i-1, j-1, r-1, b]:
                return Ricostruisci(X, Y, C, i-1, j-1, r-1, b) + X[i]
                
        elif colore == 'B' and b > 0:
            if C[i, j, r, b] == 1 + C[i-1, j-1, r, b-1]:
                return Ricostruisci(X, Y, C, i-1, j-1, r, b-1) + X[i]
                
        // Se non è stato preso, andiamo nella direzione del massimo tra i due rami di esclusione
        if C[i-1, j, r, b] >= C[i, j-1, r, b]:
            return Ricostruisci(X, Y, C, i-1, j, r, b)
        else:
            return Ricostruisci(X, Y, C, i, j-1, r, b)
```

---

## 5. Complessità
* **Spazio**: La tabella DP ha dimensione $m \times n \times 4 \times 3$, quindi richiede $O(m \cdot n)$ spazio (poiché i budget sono costanti $3$ e $2$).
* **Tempo**: Il riempimento della tabella ha $4$ cicli annidati, dove le due dimensioni esterne vanno fino a $m$ e $n$, e le interne sono costanti ($4$ e $3$). Quindi il tempo di calcolo è $O(m \cdot n)$.
