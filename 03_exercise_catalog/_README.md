# 03_exercise_catalog

Contiene il catalogo strutturato degli esercizi.

## File principali

- `index_by_topic.md`
- `index_by_exam.md`
- `index_by_difficulty.md`
- `exercises/`

## Template

Usare `templates/exercise_template.md`.

## Errori da evitare

- Non creare esercizi senza fonte.
- Non lasciare gli indici non aggiornati.
- Non duplicare esercizi equivalenti.
