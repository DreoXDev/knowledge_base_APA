# templates

Contiene i template Markdown da usare per creare nuove note.

## Template disponibili

- `exercise_template.md`
- `method_template.md`
- `theory_template.md`
- `exam_template.md`
- `handwritten_note_template.md`
- `pattern_template.md`

## Errori da evitare

- Non modificare un template per adattarlo a un singolo caso.
- Se serve un nuovo campo ricorrente, aggiornare anche `AI_CONTEXT.md` o il workflow.
