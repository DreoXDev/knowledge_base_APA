# 02_transcriptions

Contiene trascrizioni e prime interpretazioni delle fonti.

## Sottocartelle

- `exams/`: trascrizioni degli appelli.
- `handwritten_notes/`: interpretazioni degli appunti manoscritti.

## Template

- Appelli: `templates/exam_template.md`.
- Appunti manoscritti: `templates/handwritten_note_template.md`.

## Errori da evitare

- Non catalogare gli esercizi solo qui.
- Non perdere il riferimento alla fonte originale.
- Segnare ambiguita con `[!Warning]`.
