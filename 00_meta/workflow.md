# Workflow

## Fase 1 - Setup repo

1. Creare la struttura cartelle.
2. Creare `README.md`.
3. Creare `AI_CONTEXT.md`.
4. Creare `PROJECT_STATUS.md`.
5. Creare `TODO.md`.
6. Creare tutti i `_README.md`.
7. Creare i template.

## Fase 2 - Inserimento fonti

1. Copiare gli appelli in `01_sources/exams_raw/`.
2. Copiare gli appunti in `01_sources/notes_raw/`.
3. Aggiornare `01_sources/source_inventory.md`.
4. Non modificare mai i file originali.

## Fase 3 - Trascrizione e interpretazione

Per ogni appello:

1. Creare un file in `02_transcriptions/exams/`.
2. Separare ogni esercizio.
3. Annotare ambiguita e dubbi.
4. Non risolvere ancora, se non necessario.

Per ogni PDF manoscritto:

1. Creare un file in `02_transcriptions/handwritten_notes/`.
2. Interpretare il contenuto per argomento.
3. Segnare parti dubbie con `[!Warning]`.
4. Collegare metodi e teoria estratti.

## Fase 4 - Catalogazione esercizi

1. Creare una nota in `03_exercise_catalog/exercises/`.
2. Usare `templates/exercise_template.md`.
3. Assegnare argomento, difficolta e stato.
4. Collegare teoria e metodo.
5. Aggiornare gli indici.

## Fase 5 - Estrazione pattern

1. Individuare esercizi simili.
2. Creare note in `06_exam_patterns/`.
3. Indicare base operativa comune e variazioni.
4. Collegare i metodi necessari.

## Fase 6 - Creazione metodi

Ogni volta che un pattern ricorre più di una volta, creare una nota metodo in `04_methods/`.

## Fase 7 - Creazione teoria

Creare note in `05_theory/` per gli argomenti richiesti negli esercizi o nelle domande teoriche.

## Fase 8 - Ripasso finale

Mantenere `08_review/` con flashcard, domande orali, errori comuni, checklist e piano dell'ultima settimana.
