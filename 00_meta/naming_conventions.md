# Naming Conventions

## Appelli

Formato consigliato:

```txt
YYYY-MM-DD_appello.md
```

Se la data non e nota:

```txt
YYYY-sessione-stimabile_appello.md
```

## Esercizi

Formato:

```txt
ex_<topic>_<source>_<number>.md
```

Esempi:

```txt
ex_ricorrenze_2023-06-21_01.md
ex_greedy_2024-01-15_02.md
ex_programmazione-dinamica_2022-09-10_03.md
```

## Metodi

Formato:

```txt
metodo_<argomento>.md
```

## Teoria

Formato:

```txt
teoria_<argomento>.md
```

## Pattern

Formato:

```txt
pattern_<argomento-o-famiglia>.md
```
