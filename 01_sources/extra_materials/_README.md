# extra_materials

Contiene materiali di supporto che non sono appelli o appunti manoscritti.

## Esempi

- tracce extra;
- dispense;
- link esportati;
- immagini di lavagna.

## Errori da evitare

- Non trasformare questa cartella in un deposito disordinato.
- Aggiornare `../source_inventory.md` quando si aggiunge materiale.
