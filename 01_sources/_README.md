# 01_sources

Contiene solo fonti originali o materiali grezzi.

## Sottocartelle

- `exams_raw/`: appelli passati originali.
- `notes_raw/`: PDF o immagini di appunti manoscritti.
- `extra_materials/`: materiali aggiuntivi non classificati altrove.

## Nomi file

Usare il nome originale quando e significativo. Per gli appelli, preferire `YYYY-MM-DD_appello.ext`.

## Errori da evitare

- Non modificare fonti originali.
- Non inserire soluzioni elaborate.
- Non spostare file senza aggiornare `source_inventory.md`.
