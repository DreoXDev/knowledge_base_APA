# notes_raw

Contiene appunti manoscritti originali, PDF, immagini o scansioni.

## Nomi file

Usare nomi stabili e descrittivi, per esempio:

```txt
appunti_compagna_parte-01.pdf
```

## Errori da evitare

- Non sovrascrivere PDF o immagini originali.
- Non fidarsi solo di OCR automatico.
- Segnare sempre parti dubbie nelle trascrizioni.
