# RAG Interface

Questa cartella contiene i prompt pronti da copiare nella chat usata durante l'esame.

## File principali

- `Prompt Chat Esame.md`: prompt unico iniziale da incollare nella chat.
- `prompt_rag_apa_parteI_esercizio1_lcs_ingombro.md`: modulo specifico per Parte I, Esercizio 1, LCS con ingombro.

## Come usarla

1. Aprire `Prompt Chat Esame.md`.
2. Copiare tutto il contenuto nel primo messaggio della chat.
3. Inviare poi una foto o il testo di un esercizio alla volta.

## Regola di manutenzione

I file specifici per esercizio sono sezioni modulari. Ogni nuova sezione utile durante l'esame va aggiunta anche al prompt unico `Prompt Chat Esame.md`, cosi il telefono ha un solo testo iniziale da copiare.
