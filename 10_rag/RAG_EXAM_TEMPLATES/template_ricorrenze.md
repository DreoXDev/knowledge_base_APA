# Template Ricorrenze

1. Forma: riscrivere la ricorrenza nella forma standard.
2. Parametri: identificare `a`, `b`, `f(n)` oppure il sottoproblema.
3. Caso base: indicare `T(1)` o stato iniziale.
4. Risoluzione: Master theorem, iterazione, sostituzione o DP.
5. Risultato: classe `Theta` o coefficiente finale.
6. Correttezza: breve giustificazione del metodo scelto.
