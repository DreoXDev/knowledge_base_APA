# 04_methods

Contiene metodi operativi riutilizzabili.

## Nomi file

```txt
metodo_<argomento>.md
```

## Template

Usare `templates/method_template.md`.

## Errori da evitare

- Non scrivere teoria lunga se serve una procedura.
- Non creare metodi per casi isolati senza riuso.
- Collegare sempre esercizi e pattern quando disponibili.
